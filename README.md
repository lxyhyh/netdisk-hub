# netdisk-hub

个人自用的 Android 多网盘管理客户端。把多个网盘的文件管理整合到一个 App 里。

## 项目定位

- 个人自用，非商业项目
- 非任何网盘官方客户端
- 不提供公开服务，不分发 APK
- 仅用于学习 Android + Rust + UniFFI 集成和移动端协议分析

## 技术栈

Kotlin + Rust + UniFFI，Android 原生，Jetpack Compose。

## 状态

开发中，未发布。当前处于阶段 0（接口侦察）。

## 构建

本地不可编译，所有构建通过 GitHub Actions 完成。见 `.github/workflows/`。
