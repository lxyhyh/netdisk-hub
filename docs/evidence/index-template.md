## 1. APK 基本信息

- 文件名 / 包名 / 版本 / compileSdk / dex 数量
- 【新增】主体技术栈判定：Java-Kotlin / Flutter / React Native / 其他 / 混合
  - 判定依据：dex 数量、libflutter.so / libapp.so / libhermes.so 是否存在
- 【新增】反编译覆盖率：应产出类数 / 实际产出类数 / 缺失数 / 缺失率
  - 缺失类清单（至少列关键缺失类）
  - 缺失原因（可查时填写，不可查标"待确认"）
- 【新增】加固 / 风控 SDK 清单：加固壳 / 证书绑定 / 设备指纹 / 风控 SDK
  - 无则写"未发现"并注明搜索方式
