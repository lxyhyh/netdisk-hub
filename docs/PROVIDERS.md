### 关于「Flutter 主体」的含义

**静态反编译 dex 拿不到网盘文件协议**，只能得到入口壳与原生桥接。这直接影响静态侦察的
投入产出比（详见 docs/evidence/apk-inventory.md 第 3.1 节）。

> **T-002c 补充（2026-11-28）**：这句话只对**文件业务协议**成立。**账号登录协议**在夸克与阿里身上

### 列定义

**原生登录可行性**（T-002c 后的四档，与 login-feasibility.md 第 1 节一致）

- **原生登录可行**：有完整证据证明可通过官方客户端协议，在本项目自己的 APP 内主动换取会话，不依赖 OAuth、WebView、网页 cookie 等不合格路径
- **需攻关**：已确认存在符合要求的官方客户端原生认证路径，但签名、设备指纹、版本校验、native 注入等关键环节仍需解决
- **不可行**：已有证据证明官方客户端协议不满足项目登录约束，或命中资料缺失兜底规则
- **未知**：当前资料不足，不能证明可行也不能证明不可行；必须明确缺少什么资料

> **「需攻关」不是「可行」的同义词，「未知」不是「不可行」。** 三档都**不进 MVP 硬准入**；「需攻关」可进候选，但必须先完成攻关。

**登录类型**

- 账号密码
- 短信验证码
- 扫码
- 混合（多种方式并存）
- OAuth（不合格）
- 未知

## 4. 准入规则

- 原生登录可行性 = **原生登录可行**：是进入阶段 2 的硬准入条件
- 原生登录可行性 = **需攻关**：可进入阶段 2，但必须先完成攻关任务；**未完成攻关前不得计入 T-005 的「可行」分子**
- 原生登录可行性 = **不可行**：从 MVP 移除；**不得**因此降级为 OAuth/WebView/cookie
- 原生登录可行性 = **未知**：不进阶段 2，先补侦察（动态分析）

> 本规则的直接后果（T-002c 实测时）：T-005 的 Go 判据是「可行集合 ≥ 2」，当时**只有坚果云 1 个「可行」**。
> **T-006 后**：百度改判「原生登录可行」，可行集合变为 **2**（坚果云 + 百度），形式上满足 Go 判据。
> 但 T-005 的历史 No-Go 结论**不改写**，也不自动锁定 MVP；是否重跑 Go/No-Go 由用户决定。详见 `docs/evidence/login-feasibility.md` 第 7 节与本节 §6.7。

**建议先做：天翼云盘 + 坚果云。**

理由：

1. **认证方式差异大**：天翼是运营商体系（短信/账号密码），坚果云是独立
   WebDAV 风格账号体系，两者登录协议完全不同 —— 能真正验证 `connect` 抽象。
2. **上传协议差异大**：天翼走云盘协议（分片、可能秒传），坚果云有 WebDAV
   语义，两者上传实现无重叠 —— 能真正验证 `upload` 抽象。
3. **资料可得性**：两者 APK 都在手，且天翼已确认非 Flutter 主体
   （虽有 Flutter 运行时）；坚果云仅 2 dex、无加固，是最容易侦察的一个。
4. **风险分散**：一个高风险（天翼，运营商风控）配一个低风险（坚果云，
   协议相对透明），避免两个都卡在同一类问题上。

**备选**：若天翼风控过重，用 123云盘 替换（同为简单账号体系，但为 Flutter）。

### 6.2 T-002b 复核结论

**T-002b 的实测结果推翻了原建议的两条依据。**

| # | 原依据 | 复核结果 |
|---|---|---|
| 1 | 天翼认证方式与坚果云差异大，能验证 `connect` | **无法验证。** 天翼尚未侦察，认证方式仍为「未知」，差异度无从判断（依据是推测，非事实） |
| 2 | 天翼上传协议差异大（分片/秒传） | **同上，纯推测。** 无任何证据表明天翼用分片上传 |
| 3 | "天翼已确认非 Flutter 主体" | **事实错误。** `docs/evidence/apk-inventory.md` §3 与 §3.1 明确记载天翼云盘是 **Flutter 主体**（`assets/ijm_libexec.so`、`libexecmain.so`、`libsecurity.so`），jadx 反编译 dex 拿不到网盘协议 |
| 4 | 坚果云最容易侦察 | **成立。** T-002b 实测：2 dex、无加固、无证书绑定，8006 个类全静态可读，已产出完整索引 |

**新增的反向证据**：

- **天翼云盘 APK 387 MB，是 9 个网盘里最大的一个**，且为 Flutter 主体。
  按 T-002b 的实测经验，对 Flutter 主体做静态侦察的产出接近于 0
  （见 `index-坚果云.md` §11.5），也就是说**天翼连"资料可侦察"这一条都不满足**。
- 反过来，坚果云已具备最完整的静态资料，是唯一一个**当前就能写代码**的。
