## 1. UI 框架锁定

**唯一框架：Jetpack Compose + Material 3。**

| 项 | 决定 |
|---|---|
| 声明式 UI | Jetpack Compose（Compose BOM 统一版本） |
| 设计语言 | Material 3（`androidx.compose.material3`） |
| 主题 | 直接用 M3 的 `ColorScheme` / `Typography` / `Shapes` 默认体系 |
| 页面载体 | 全部为新 Compose 页面 |

**不引入其他 UI 库。** 明确禁止：

- 第三方 UI 组件库、UI 框架、UI 主题库
- 再引入一套设计系统（自建 Design System 不在本项目范围）
- 以 XML View 体系作为新页面载体
- 页面级的自定义绘制动画框架

允许范围：Compose 官方构件 + Material 3 + AndroidX 官方扩展库。

> 待确认项见第 6 节（图标方案、图片加载库是否触犯"其他 UI 库"）。

## 2. UI 分层

```
Compose (UI)
    ↓ UiState / Intent
ViewModel
    ↓ 调用
UseCase
    ↓
UniFFI interface
    ↓
Rust 核心（Adapter 藏在内部）
```

### 各层职责

| 层 | 只做 | 禁止 |
|---|---|---|
| Compose | 渲染 UiState、发出 Intent | 直接调 UniFFI；出现任何网盘专有概念 |
| ViewModel | 持有 UiState、编排 UseCase、处理生命周期 | 写业务规则；拼请求；碰网络 |
| UseCase | 单次原子业务操作（列目录、上传、删除…） | 渲染；持有 UI 状态 |
| UniFFI | 跨语言边界 | —— |

### UI 层薄的核心规则

1. **依赖方向单向**，UI 层不得反向被业务层依赖。
2. **UI 层只认统一抽象**：可出现的类型是 `AccountId`、`RemoteFile`、
   `TransferTask`、`ProviderKind` 这类通用概念。
3. **UI 层禁止出现**：网盘专有的签名参数、设备指纹、分片协议、验证码流程、
   具体请求 URL / header / 字段名、真实 token、cookie。
4. **UI 层不判断"哪个网盘怎么落地"**：所有网盘差异在 Rust Adapter 内部消化，
   UI 只看到 UniFFI 的统一方法。
5. **UI 层不写重试/续传/断点策略**：这类逻辑属于 UseCase 或 Rust 侧。
6. 新增一个网盘时，**UI 层不应产生任何改动**——这是判断分层是否守住的验收口径。

## 3. 关键页面清单

MVP 只做这 5 个页面，不做更多。

| # | 页面 | 目的 | MVP 内含 |
|---|---|---|---|
| P1 | 账号管理 | 多账号接入与状态维护 | 添加/移除账号、登录状态展示、重新登录 |
| P2 | 统一文件列表 | 跨网盘浏览与搜索 | 目录浏览、路径导航、搜索、多选 |
| P3 | 文件操作 | 对选中条目的动作 | 下载、上传、重命名、删除、新建文件夹 |
| P4 | 任务队列 | 传输可见与可控 | 列表、进度、暂停/取消、失败重试、失败原因 |
| P5 | 设置 | 少量全局开关 | 并发与限速入口、日志与诊断入口、账号入口、关于 |

MVP 外、本文不设计的页面：分享、同步、备份、在线预览、回收站、传输历史归档。

### 页面关系

```
P5 设置 ──> P1 账号管理
P2 文件列表 ──> P3 文件操作
P2 文件列表 ──> P4 任务队列
P4 任务队列 ──(失败项)──> 错误详情
```

## 4. 低保真线框

以下为结构示意，不是视觉稿。所有页面都必须覆盖三态：加载中 / 空 / 错误。

### P1 账号管理

```
[账号管理]                      +
────────────────────────────────
 ● 天翼云盘        已连接
   137****6789
   [重新登录] [移除]
────────────────────────────────
 ● 坚果云          已过期  !
   [重新登录] [移除]
────────────────────────────────
 ○ 添加账号
   百度 天翼 夸克 坚果 蓝奏
   123  UC  阿里 迅雷
────────────────────────────────
```

- 每行展示：网盘名、连接状态（已连接/已过期/未授权）、脱敏账号标识、两个动作
- 点  或"添加账号"进入网盘选择，选中后交给 Rust 侧发起授权
- 无账号时：整页空态 + 一个"添加账号"主按钮

### P2 统一文件列表

```
[文件 · 文档]              [筛选]
────────────────────────────────
 来源: [全部 ▾]   排序: [名称 ▾]
 [ 搜索                       ]
────────────────────────────────
 📁 项目资料             —
 📄 报告.pdf          2.3 MB
 📄 预算.xlsx         128 KB
 📁 备份                 —
────────────────────────────────
 [上传] [新建文件夹]    [多选]
```

- 顶栏显示当前路径；返回键逐级上跳
- "来源"过滤：全部 / 单个网盘
- 每行：类型图标、名称、大小；多选态下显示复选框
- 长按进入多选；多选后底部栏切换为批量动作
- 错误态必须能显示"哪个网盘失败 + 失败原因"，可重试

### P3 文件操作

```
[文件操作] 报告.pdf
────────────────────────────────
 来源: 天翼云盘 / 文档
────────────────────────────────
 下载
 重命名
 新建文件夹
 删除                      ← 危险
────────────────────────────────
 [取消]
```

- 单条目操作用底部面板；多选时只保留可批量执行的动作（下载、删除）
- 删除必须二次确认，确认文案包含条目数量
- 重命名与新建文件夹为单行输入弹窗
- 操作提交后不阻塞页面，结果进 P4 任务队列，用轻提示反馈受理

### P4 任务队列

```
[任务]
────────────────────────────────
 进行中 2   等待 1   失败 1
────────────────────────────────
 ↑ 上传 视频.mp4
   天翼云盘  45%
   ▓▓▓▓▓░░░░░  1.2 MB/s
   [暂停] [取消]
────────────────────────────────
 ↓ 下载 报告.pdf
   坚果云    100%  已完成
────────────────────────────────
 ↑ 上传 备份.zip
   阿里云盘  等待中
────────────────────────────────
 ! 下载 素材.zip  失败
   原因: 登录已过期
   [重试] [去重新登录]
────────────────────────────────
```

- 每项展示：方向、文件名、所属网盘、进度、速度、状态
- 失败项必须给可读原因 + 一个可执行动作
- 队列为空时给空态，不隐藏入口
- 不在此页展示技术细节（重试次数、分片序号等）

### P5 设置

```
[设置]
────────────────────────────────
 账号管理                    >
 并发与限速                  >
 日志与诊断                  >
 关于                        >
────────────────────────────────
 日志脱敏            [ 开 ]
```

- 一级列表 + 进入二级页；MVP 二级页允许只做占位
- "日志脱敏"默认开，且不可在 MVP 关闭（见 SECURITY.md）

## 5. 非目标

以下明确**不做**，写进范围冻结：

1. **不做高保真视觉稿**：不产出像素级设计稿、不做可用性测试、不做视觉走查。
2. **不做自定义设计系统**：不自建 color / type / shape token 体系，
   不自建组件库，直接用 Material 3 默认值。
3. **不做动效规范**：不做转场编排、不做手势动画规格，用框架默认转场即可。
4. 不做平板 / 折叠屏专属布局（跟随系统默认拉伸）。
5. 不做多语言（MVP 只中文）。
6. 不做无障碍专项评审（只要求基本的可点击区域与语义标签）。
7. 不做主题定制与皮肤（明暗跟随系统）。

判据：任何 UI 讨论若落到"更好看"，一律推到 MVP 之后。

## 6. 待确认

| # | 问题 | 说明 |
|---|---|---|
| 1 | 图标方案 | Material Icons 是否算"其他 UI 库"？默认按"官方扩展可用"处理 |
| 2 | 图片/视频缩略图 | 列表若要缩略图需引入图片加载库，与本任务"不引入其他 UI 库"冲突；MVP 建议不显示缩略图 |
| 3 | 底部导航还是单栈 | MVP 只有 5 个页面，建议单栈 + 顶栏入口，不做底部导航栏 |
| 4 | 搜索范围 | "统一搜索"是只搜当前网盘，还是跨全部已连接账号并发搜索？影响 P2 交互与耗时提示 |
| 5 | 多选批量上限 | 批量下载/删除是否需要条数上限提示 |

以上第 1、2 项会影响 UI 框架锁定条款，需在进入阶段 1 前拍板。
