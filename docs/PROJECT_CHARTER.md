# 项目章程（PROJECT_CHARTER）

- 状态：草案 v0.1
- 产出任务：T-001
- 最后更新：2026-11-26

## 1. 唯一目标

一个 Android 客户端管理多个网盘文件，**个人自用**。

把百度网盘、天翼云盘、夸克网盘、坚果云、蓝奏云、123云盘、UC网盘、阿里云盘、
迅雷云盘整合到同一个 App 里，用一个界面管理所有网盘文件。

## 2. MVP 范围

- Android 客户端
- 多账号
- 统一文件列表 / 搜索
- 下载 / 上传 / 重命名 / 删除 / 新建文件夹
- 任务队列
- **先 2 个网盘跑通**（选哪 2 个见 PROVIDERS.md）

## 3. 非目标

分享站、同步盘、在线预览、跨盘秒传、自动备份、多租户、商用。
登录相关的非目标另见 SCOPE.md「非目标」章节，约束更强。

## 4. 成功标准

1. 能登录
2. 能列目录
3. 能下载
4. 能上传
5. 能重命名
6. 能删除
7. 接口失败可诊断
8. **新增网盘只加 Rust Adapter**，Kotlin / UI 层不改动

## 5. 合规边界

- 个人自用
- 不公开接口
- 不散播凭据
- 不散播逆向产物

## 6. 登录方式

### 登录方式（硬目标）

在 APP 自身 UI 内完成原生登录（账号密码 / 短信验证码 / 扫码），
由 Rust Adapter 通过官方客户端登录协议主动换取会话 token，
token 存入 Android Keystore。
扫码登录的 token 必须由客户端协议换取，不得从 WebView 抓取。

**唯一合格路径：**

- APP 内输入账号密码，调官方客户端登录接口
- APP 内短信验证码登录，调官方客户端接口
- APP 内展示二维码，官方客户端协议换 token（二维码只是展示，不得抓 WebView cookie）

**不合格方式（一律禁止，不得作为降级方案）：**

- OAuth 第三方授权（有限制，无法达到官方 APP 同等能力）
- 跳转浏览器授权后回调（属于 OAuth 变体）
- WebView 登录后提取 cookie/token
- 手动粘贴 cookie/token
- 网页端会话复用
- 任何“跳出去授权再回来”的间接登录
- 任何“从浏览器/WebView 捡凭证”的被动获取

**判定标准：**

登录凭证必须由 Rust Adapter 通过官方客户端登录协议主动换取；
任何间接授权、WebView 抓取、手动导入的方式都不合格。

**若某网盘原生登录不可行：**

记录为“不可行”并附证据，该网盘从 MVP 移除，不硬凑。

### 登录方式判定表

| 登录方式 | 是否合格 | 说明 |
|---|---|---|
| APP 内输入账号密码，调官方客户端登录接口 | ✅ 唯一目标 | 与官方 APP 一致 |
| APP 内短信验证码登录，调官方客户端接口 | ✅ 唯一目标 | 与官方 APP 一致 |
| APP 内展示二维码，官方客户端协议换 token | ✅ 可接受 | 二维码只是展示，token 必须由客户端协议换取，不得抓 WebView cookie |
| OAuth / 第三方授权跳转 | ❌ 禁止 | 有限制，无法达到官方 APP 同等能力 |
| 内嵌 WebView 登录，拦截 cookie/token | ❌ 禁止 | 移动端登录态不可维持，且非官方客户端协议 |
| 手动粘贴 cookie/token | ❌ 禁止 | 非原生登录 |
| 网页端会话复用 | ❌ 禁止 | 同上 |
| 跳转浏览器授权后回调 | ❌ 禁止 | 属于 OAuth 变体 |
