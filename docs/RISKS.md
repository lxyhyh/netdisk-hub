## 风险说明

### R16 UniFFI 兼容矩阵

UniFFI 官方只提供 crate 与 bindgen 的版本矩阵，不含 Gradle 侧集成。
本项目通过**自定义 Gradle Exec 任务**调用 `uniffi-bindgen`，不依赖第三方插件，
因此失败面收敛在"任务编排"而非"插件兼容"。

### R17 AGP 内置 Kotlin

AGP 9.x 起内置 Kotlin 支持。若只在版本目录写 `kotlin = "2.4.21"` 而不按内置机制固定，
实际可能仍用 AGP 自带的 KGP。**必须显式固定，且不得重复应用 `org.jetbrains.kotlin.android`**，
否则会触发插件冲突。
